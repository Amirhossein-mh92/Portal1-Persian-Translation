# Portal1-Persian-Translation
Persian (Finglish) subtitle translation for Portal 1

========================================
Installation
========================================

1. Download and extract the mod files.

2. Inside the extracted folder, you will find the following:
- An "install" folder containing the mod files
- An "uninstall" folder for removing the mod
- A text file with instructions in Persian

3. Open the "install" folder, copy all its contents,
and place them into the Portal 1 installation folder:
Steam\steamapps\common\Portal 1\

4. When prompted to merge or overwrite files,
click Yes.

5. Launch the game. Subtitles and captions will automatically
display in Finglish (Persian).

6. Enjoy the game!

========================================
Uninstallation
========================================

1. Open the "uninstall" folder.

2. Copy all its contents and place them into the Portal 2
installation folder:
Steam\steamapps\common\Portal 2\

3. When prompted to merge or overwrite files,
click Yes.

4. Launch the game. Subtitles will revert to the original English.
